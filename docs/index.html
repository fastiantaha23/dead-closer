How it works

A LangGraph state machine. Decisions are deterministic code; the language model only reads the lead's text and words an already-decided plan, so there is nothing for a prompt injection to hijack.

ingestLoad lead, tenant, long-term memory. Redact PII. Short-term memory = checkpointed thread.
guard_inOpt-out, abuse, legal threat, distress, injection, flood. Code, not LLM.
understandBudget, timeline, slot choice, intent. Claude tool call or offline rules.
rememberFacts to long-term memory, score the lead, upgrade billing when qualified.
decide (supervisor)Routes to qualifier, closer, info, objections or follow-up agent.
composePlan to SMS. Claude rewrite or templates.
guard_outNo invented prices, links, fair-housing steering, AI denial, tenant leaks. Fallback to template.
deliverQuiet hours, frequency cap, STOP footer, persist, schedule follow-ups and reminders.
schedulerFollow-up cadence ~3h, 1d, 3d, 7d, 14d, 28d; angles chosen by UCB from this tenant's reply history.
billingFee pending on a qualified booking, earned when the visit time passes, void on cancel.

Short-term memory

Each lead is a LangGraph thread. The checkpointer keeps the rolling conversation window and a running summary of older turns.

Long-term memory

Per-lead facts, preferences and episodes survive weeks (a returning lead is greeted with what they wanted). Per-tenant playbook learns which follow-up angles get replies.

Multi-tenant

Every row, tool call and memory is scoped by tenant; API keys are hashed; tenants cannot see each other's leads, inventory or learnings.

Integrate in minutes

Point your lead form or CRM webhook at one endpoint. The reply is returned synchronously; pull the outbox into Twilio, WhatsApp or email.

curl -X POST $HOST/v1/leads \
  -H "Authorization: Bearer $DEADCLOSER_KEY" -H "Content-Type: application/json" \
  -d '{"name":"Priya","phone":"+15125550101","message":"Interested in the Mueller home, budget 450k","item_id":"RE-101"}'

# -> {"lead_id":"l_...","reply":"Hi Priya! Dana here, Skyline Realty's virtual assistant...","latency_ms":12,"within_sla":true}

curl -H "Authorization: Bearer $DEADCLOSER_KEY" $HOST/v1/billing     # fees: pending / earned / void
curl -H "Authorization: Bearer $DEADCLOSER_KEY" $HOST/v1/outbox      # messages to send via your SMS provider
Dead Closer. Open source. The demo above uses sandbox data and a virtual clock; no messages are sent to real phones.
